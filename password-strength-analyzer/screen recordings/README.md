## ✨ Key Features

* 🎨 **Dynamic Color Feedback:** Instant visual indicator reflecting password complexity.
* 👁️ **Show / Hide Toggle:** Easily reveal or obscure password text.
* 🧹 **One-Click Clear:** Instantly wipe the input field.
* 🎲 **Smart Password Generator:** Suggests strong, unique passwords and tests them for potential faults.
* 📋 **Clipboard Integration:** Quickly copy generated passwords with one click.
